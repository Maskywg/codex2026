# codex2026

Initial project scaffold.

## Structure

- `src/`: application source code
- `tests/`: automated tests
- `scripts/update_playoff_data.py`: pulls official playoff schedule and injury reports
- `data/playoffs-data.js`: generated frontend data file

## Update Data

Run:

```bash
python3 scripts/update_playoff_data.py
```

Then reopen or refresh `index.html`.
